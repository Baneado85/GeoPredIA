# 📊 Modelado en SAP Analytics Cloud (SAC)

## Pasos para Configurar el Modelo en SAC:
1. Crear un nuevo **Model** importando los datos desde SAP HANA Cloud.
2. Definir las dimensiones: `ZoneID`, `Region`, `Scenario`.
3. Crear las medidas calculadas según `measures/formulas.txt`.
4. Construir la **Story** de Ficha de Evaluación con gráficos de dona para la división de riesgos y gráfico de barras comparativo de zonas.
5. Habilitar la exportación de tabla mediante **Export -> Point of View (POV)**.
